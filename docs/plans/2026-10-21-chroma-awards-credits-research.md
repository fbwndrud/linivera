# Chroma Awards 시즌 2 — 참여 기업·무료 크레딧 조사

확인일: 2026-10-21 (한국 시간). 공식 홈페이지와 시즌 2 Promotions의 공개 화면을 직접 열람했다. 가입·코드 발급·결제는 실행하지 않았다. 이 문서는 조사 기록이며 설계 정본을 변경하지 않는다.

## 핵심 결론

- 시즌 2의 광고 규모는 **전체 참가자 대상 총 $1M+ 무료 체험·프로모션**, **$450,000+ 현금 상금·여행 혜택**이다. 참가자 한 명에게 $1M를 주는 구조가 아니다. [주최사 발표](https://elevenlabs.io/blog/chroma-awards-season-two-announcement)
- 홈페이지의 **$3M+ credits / $700K+ cash는 모든 시즌 누적**이다. 시즌 2 참가자 지급액으로 해석하면 안 된다. [홈페이지](https://chromaawards.com/)
- 현재 공개된 정액 크레딧은 fal $100, LTX Explore $75, Reactor $150, VEED API $50로, 서로 다른 서비스의 표시 금액을 단순 합산하면 $375다. 전부 우리 계정에 지급되는지는 로그인 후 자격·재고 확인 전에는 확정할 수 없다. 현금화·타 서비스 간 이전이 되는 잔액도 아니다. [시즌 2 Promotions](https://submit.chromaawards.com/pack)
- Runware $50 API와 TapNow $100는 **Coming Soon**이다. 현재 가용 예산으로 잡지 않는다. ElevenLabs·CapCut·Luma 등은 무료 지급이 아닌 유료 구독 할인이다. [시즌 2 Promotions](https://submit.chromaawards.com/pack)
- 리니베라의 이미지·영상 실험에는 fal, LTX Explore, PixVerse의 실용성이 높다. VEED는 립싱크·배경 제거·음성 정리에, Meshy/Hyper3D/Nimble Fox는 3D 또는 게임 실험을 실제로 할 때 사용한다. 이 우선순위는 제품 기능에 근거한 제안이며 주최 측의 권고가 아니다.

## 리니베라에 맞춘 사용 순서 제안

1. **작품의 한 장면을 고정한 합성 fixture**로 이미지 일관성·짧은 움직임·내레이션을 비교한다. fal $100, LTX Explore $75, PixVerse Pro 1개월을 첫 후보로 삼는다. 이는 서로 다른 방식의 지원이므로 테스트 비용은 서비스별로 기록한다.
2. 영상 생성의 결과가 채택되면 VEED API $50로 립싱크·배경 제거·음성 정리를 검증한다. 영상 편집 기능이 필요하지 않으면 혜택만을 위해 의존성을 추가하지 않는다.
3. ElevenLabs·CapCut은 기존 구독 또는 무료 기능과 먼저 비교한다. 할인 기한이 짧다는 이유만으로 구매하지 않는다. 음성·음악 품질 또는 편집 생산성의 개선이 확인되면 할인 구매를 검토한다.
4. Meshy/Hyper3D는 인터랙티브/게임 또는 3D 배경이 선택됐을 때 활성화한다. 1개월 구독은 실제 제작 일정을 잡고 리딤하되 각 코드의 만료일보다 늦추지 않는다.
5. Runware/TapNow 및 기타 Coming Soon은 이후 조건이 공개되면 검토한다. 이미 실행 중인 제작을 이 혜택에 의존시키지 않는다.

## 발급 전에 남은 확인

- 현재 로그인 계정에 적용되는 자격, 잔여 코드 재고, 신규/기존 고객 제외 조건.
- 국가 제한, 한국 결제·계정 적용 가능 여부. 공개 카드에 한국 제외 문구를 보지 못했으나 한국 계정 적용을 검증한 것은 아니다.
- 카드 요구, 자동 갱신, 해지 시점, 잔액 만료 및 미사용 잔액 소멸. fal의 billing details 요구 외에는 카드 조건을 일반화할 수 없다.
- API와 웹 구독의 잔액 공유·상업 이용 허용 범위. 특히 LTX Explore, Meshy Pro, PixVerse Pro를 API 크레딧으로 간주하지 않는다.
