# 0.1.3 문서·버전 정합성

기준 main: `722137424f52c6af09df71dc31d714bd22ad1263` (#2~#9 병합 완료).
사용자 요청은 README·공개 문서를 이번 구현에 맞추고 패치 버전을 0.1.2에서 0.1.3으로 올리는 것이다.
주 작업 트리와 원래 점검/구현 트리의 사용자 변경은 보존하고 별도 깨끗한 체크아웃에서 작업한다.

## 수정 범위

- CHANGELOG를 설치 패키지에 동봉해 README와 시작 안내의 변경 이력 링크도 설치 후 열린다.
- root/viewer manifest와 lock을 0.1.3으로 맞춘다. 의존성 판본·출고 명세 hash는 바꾸지 않는다.
- 영문·한국어 README, CHANGELOG와 문서 첫 화면에 자산 계보·대용량 파일·실행/후보·회차 선택·
  P0~P4 구조/배포 연결·입력/연결 준비·맥락 묶음·카탈로그 보존을 안내한다.
- 시작/설치/호환/검증/Resource 문서와 예제 설명의 오래된 도구 수·지원 범위·검증 수치를 정리한다.
- 공개 GitHub 자산은 조회 시 v0.1.2가 최신이고 v0.1.3은 없다. 새 공개 패키지가 없는 동안
  기존 설치 URL과 v0.1.1 예시 ZIP/스크린샷을 보존하고, 소스 0.1.3과 공개 0.1.2를 명확히 구분한다.
- 실제 공급자 준비·유료 생성·37개 파트너 전체 실행·복원·법적 승인으로 과장하지 않는다.

## 검증

기존 버전/공개 MCP/동봉 guide 계약, 로컬 문서 링크와 설치 tarball 링크, Studio 테스트와 build,
lint/typecheck 및 전체 검사로 검증한다. 설치 tarball은 dev dependency 없이 새로 설치하고
MCP identity와 실제 23개 도구, 공개 예제·연속성·출고 hash를 검사한다. 원격 CI는 추가하지 않는다.
배포 자산과 합성 실행 출력은 커밋하지 않는다. 공개 릴리스 게시와 예전 릴리스 교체는 별도 작업이다.
